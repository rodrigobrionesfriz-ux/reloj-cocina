# Reloj Cocina

Launcher Android para la tablet Philips PI3100 (7", 1024x600, Android 4.1/4.2) como reloj de pared de cocina.

- Izquierda: reloj analógico con 12, 3, 6 y 9 grandes, segundero y fecha. Tocar el reloj abre alarmas/temporizador.
- Derecha arriba: calendario mensual (semana parte lunes), puntos en días con eventos del calendario del equipo. Tocar un día muestra sus eventos; tocar el texto de eventos abre la app Calendario; tocar el título vuelve a hoy.
- Derecha abajo: caja de apps con YouTube y Netflix fijas (si no están instaladas abren la web), botón "Agregar" y "Todas". Mantener presionada una app la quita de la caja.
- Pantalla siempre encendida; de 23:00 a 07:00 baja el brillo, un toque lo sube por 1 minuto.

## Compilar
Subir a un repo de GitHub. La acción "Compilar APK" genera el artefacto `reloj-cocina-apk`.
